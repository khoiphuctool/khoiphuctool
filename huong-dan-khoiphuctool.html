🔐 Sửa đúng Office Agile SHA-1 + AES-128 GPU/OpenCL — MỚI

Phiên bản này fix lỗi nghiêm trọng trong GPU kernel cho Microsoft Office Agile Encryption (ECMA-376) với SHA-1 + AES-128. Kernel cũ dùng blockKey bytes sai thứ tự (little-endian nhầm), gây ra kết quả sai hoàn toàn khi dò mật khẩu file xlsx/docx mới.

✅ Đã sửa trong phiên bản này:
  • BlockKey bytes đúng: FE A7 D2 76 3B 4B 9E 79 và D7 AA 0F 6D 30 61 34 4E (xác nhận từ Hashcat m09500)
  • Bỏ hoàn toàn padding giả (b'\x00'*n) trong encryptedVerifierHashValue
  • Parser validate đúng: reject nếu keyBits≠128, saltSize≠16, hoặc dữ liệu ngắn hơn spec
  • CPU reference implementation đúng chuẩn để so sánh với GPU
  • 57 kiểm tra tự động: SHA-1 NIST, AES-128 NIST, KDF, verify đúng/sai password, GPU comparison và no false positive
